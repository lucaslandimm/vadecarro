# Vá de Carro

## Sobre o Projeto

Este é um projeto acadêmico de escopo reduzido, desenvolvido durante duas aulas práticas, com duração total estipulada de quatro horas. A finalidade principal deste repositório é projetar construir uma única interface de recurso (ex: a página do cardápio e carrinho de compras) para consolidar e revisar conceitos de marcação e estilização web.

Este layout estático serve como alicerce estrutural para as próximas etapas da disciplina, onde implementaremos interatividade e manipulação do DOM.

## Temática da equipe

Um site de aluguel de carro que elimina burocracias e a falta de transparência na busca por veículos para o cliente, enquanto automatiza vendas e reduz a ociosidade da frota para a locadora. 

## Objetivos do projeto

- Revisão e aplicação de **HTML Semântico** (uso correto de tags estruturais como `<main>`, `<section>`, `<article>`).

- Desenvolvimento de Layout utilizando **CSS Flexbox e CSS Grid Layout**.

- Preparação de classes e identificadores para futura manipulação com **JavaScript**.

- Prática de versionamento de código e trabalho colaborativo com **Git e GitHub**.

## Tecnologias Utilizadas

- **HTML5**

- **CSS3** (incluindo Grid Layout & Flexbox)

- *(Futuramente: JavaScript)*

## Status do Projeto

Em desenvolvimento (Fase 1: Interface Estática em construção). Funcionalidades de interação de botões, cálculos e respostas dinâmicas serão adicionadas nas próximas atualizações.
